PC DROP — стартовый проект Telegram Mini App

ЧТО УЖЕ ЕСТЬ
- Telegram-бот: /start, /drop (раз в 3 часа), /inventory, /sell, /balance, /daily.
- Мини-приложение с тёмным интерфейсом: главная, карточки, продажа, магазин-витрина, сборка ПК.
- SQLite сохраняет баланс, карточки, таймеры и сборку.
- Проверка Telegram initData на сервере для запросов из Mini App.

ВАЖНО
Это первая рабочая основа, а не законченная игра. Пока нет полноценной покупки в магазине, обменов, рейтинга, заданий и продвинутой совместимости комплектующих. Их будем добавлять поэтапно. Перед публичным запуском нужно отключить локальный dev-вход, проверить настройки базы данных и развернуть сайт по HTTPS.

ЧТО НУЖНО ДЛЯ ЗАПУСКА
1. Установить Python 3.12 или новее на компьютер.
2. Открыть папку проекта в терминале.
3. Установить зависимости: pip install -r requirements.txt
4. Создать переменную окружения BOT_TOKEN с токеном от @BotFather.
5. Запустить локальный сервер: uvicorn main:app --reload
6. Для теста страницы открыть http://127.0.0.1:8000/ . В локальном просмотре используется тестовый игрок 10001.

ДЛЯ TELEGRAM MINI APP
- Mini App требует публичный HTTPS URL.
- После размещения проекта указать PUBLIC_URL равным HTTPS-адресу сервера.
- Перезапустить приложение.
- Бот отправляет кнопку Mini App в /start, если PUBLIC_URL задан.
- Токен хранить только в переменных окружения/секретах хостинга; не публиковать и не отправлять другим людям.

БЕЗОПАСНОСТЬ И ХОСТИНГ
- Для production установить ALLOW_DEV_AUTH=0.
- Убедиться, что каталог данных SQLite сохраняется между перезапусками, либо использовать постоянный диск/внешнюю БД.
- Не использовать токен в публичном коде.
